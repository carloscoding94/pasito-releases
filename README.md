# Pasito para Android

Aplicación personal de objetivos, tareas y constancia. Este repositorio contiene únicamente las descargas y notas de versión; el repositorio de desarrollo es privado.

## Instalar

1. Abre [la última versión](https://github.com/carloscoding94/pasito-releases/releases/latest) y descarga el archivo APK.
2. Ábrelo en Android. Si el sistema lo solicita, autoriza la instalación desde tu navegador o gestor de archivos.
3. En Pasito, el botón Buscar actualizaciones consulta este canal público. Si hay una nueva versión, descarga y verifica el APK antes de abrir el instalador de Android.

Requiere Android 8.0 o posterior y un Android System WebView actualizado. Funciona sin conexión; solo necesita Internet para buscar y descargar actualizaciones.

## Datos y actualizaciones

Los datos se guardan en el dispositivo. Actualiza sobre la app existente para conservarlos; no la desinstales. Puedes exportar una copia JSON desde la app. Los datos del prototipo del navegador no se importan automáticamente.

Cada versión publica su APK firmado, pasito-update.json y SHA256SUMS.txt. El sistema verifica la firma del APK al instalar. Nunca se publica aquí la clave privada de firma.
